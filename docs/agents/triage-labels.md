# Triage Labels

When assigning a triage role, write the corresponding string below in the local ticket's `Status:` field. Skill role names and local strings are identical.

| Status | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation is pending |
| `needs-info` | Required information from the reporter is missing |
| `ready-for-agent` | Scope, dependencies and acceptance checks are specified; implementation can proceed without a pending human decision |
| `ready-for-human` | Implementation requires human action |
| `wontfix` | The issue will not be implemented |

These are triage roles. Wayfinding claim and resolution states are defined in the [local tracker](issue-tracker.md#wayfinding-operations).
