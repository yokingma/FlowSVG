# 连续继承的全局时间线

图解文档使用一条以毫秒计的全局时间线，场景按顺序连接；后一场景继承前一场景的最终画面状态。节拍在起点提出动作，过渡占其前段，恰好到下一个节拍起点时进入下一步。这个约定使顺序播放、暂停、跳转和静态 SVG 导出能共用同一时间求值结果；场景如需清除高亮或隐藏对象，必须显式写动作。

## 单条传递的编译时序

每拍仅声明一条 `flow` 时，核心按该拍目标视觉状态的路径长度计算移动时长：目标速度为 180 图解单位/秒，最短 400ms。标记到达后统一停留 500ms。节拍实际时长为移动时长加 500ms，替代作者 `durationMs`，后续节拍随之调整。较长的阅读时间使用独立的无传递节拍；多条传递仍共用整拍线性进度。`transitionMs` 先取作者值或原有默认值，再限制在实际节拍时长内，减少动画不改变时序。

单条传递的发送端立即高亮。到达后，接收端的填充色和描边色用 200ms 渐入；节点和连线的自动高亮随后保持 100ms，再用 200ms 渐出，拍末进入下一拍。反向传递交换发送端和接收端。逻辑 `highlighted` 标志和标记在整拍内生效；内容、几何和显式动作保留作者设定的时机。显式高亮优先，`highlightParticipants: false` 关闭自动端点着色。减少动画模式跳过渐入和渐出，保留 500ms 到达区间；多条传递保留原有同步时序与着色。播放倍率随时间轴缩放渐变，SVG 和导出求值相同的颜色。

目标几何包含继承的节点更新、分组位置、端口、可见障碍物和线宽。布局变化期间标记沿当前路径绘制；目标速度决定基准移动时长，不保证布局或镜头变化时的屏幕像素速度。

`Diagram.beats` 提供不可变的编译后节拍边界和有效说明文字。播放器步进、场景切换、导出说明文字预检与示例总时长共用该结果，避免自行相加作者时长。图解文档保持作者数据，不写入派生时间。无法表示为有限数的移动时长或累计时间通过 `DiagramValidationError` 报告受影响节拍的 `durationMs` 路径。
