# 显式视觉选项与分层状态

Status: accepted

本 ADR 是当前视觉选项决策记录；实际选项、默认值和限制以公开类型、实现和测试为准。

核心求值和 SVG 导出接受相同的可序列化主题值与减少动画标志，浏览器播放器也把当前选项传给核心；CSS 变量仅定制播放器控件。这样同一文档、时间和选项可得到一致的画面与导出结果，而不依赖浏览器计算样式。普通样式与高亮状态分层保存，显隐过渡作用于对象和关联连线；这避免取消高亮丢失最新普通颜色，以及连线在节点淡入淡出时突变。

## 已接受的强调配色扩展（待实现）

[ADR 0018](0018-serializable-emphasis-colors.md) 将可序列化视觉配置扩展到 emphasis，其 fill、stroke、markerText 分别按运行时覆盖、文档配置、当前主题默认值解析。显式高亮、flow 自动着色和浏览器节点悬停共享解析后的强调配色；悬停仍不进入核心画面或导出结果。各宿主与导出入口使用一致的解析规则，普通样式与高亮继续分层。这项扩展已确认设计，尚未实现，未配置时保留现有主题配色。
