# 浏览器渲染的双环境 GIF 导出

Status: accepted

本 ADR 是当前导出架构决策记录；支持的入口、运行时和选项以 SDK 手册、公开类型、实现和测试为准。

GIF 导出按图解时间线采样，复用核心画面求值与 SVG，不录制网页的实时播放状态。浏览器执行栅格化与编码，Node 通过无界面 Chromium 运行同一导出流程，以减少维护两套栅格化实现产生的差异；代价是 Node 首次使用时需要准备浏览器及其系统依赖。平台无关核心不依赖 DOM 或浏览器运行时。

运行资产与离线播放文件包含本地所需的 JavaScript、CSS 和图解数据，安装准备完成后的导出不得依赖网络。Chromium 单独安装，不随 SDK npm 包分发。图解文字使用系统字体及中文回退，允许跨机器字形差异；不承诺不同操作系统上的 GIF 像素一致。

浏览器自动化依赖用于 Node PNG/GIF 导出和 GIF 命令行，这些入口要求 Node 20+。核心及普通 SDK 入口支持 Node 18+；普通导入和播放不加载 GIF 编码器或浏览器自动化依赖。
