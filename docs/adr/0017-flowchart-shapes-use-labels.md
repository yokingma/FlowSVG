# 新增流程形状只承载节点标签

Status: accepted

本 ADR 记录已确认的设计边界，不表示能力已经实现或发布。具体几何、测量与验收规则见[预置形状扩展设计](../development/shape-expansion-design.md)；当前 SDK 行为仍以源码、公开类型、测试和手册为准。

新增的菱形、平行四边形、文档形和预定义流程使用纯文本节点标签 `label`，拒绝结构化节点内容 `content`。形状承担条件判断、输入输出、文件产物或子流程调用等语义，复杂说明由相邻说明节点承载。选择这一边界会限制形状内的表达能力，但避免为特殊轮廓公开标题、列表及实体图等复杂排版契约；以后增加结构化内容需要重新评估该决策。

标签使用各形状固定的矩形安全区，不沿轮廓逐行改变可用宽度，也不自动缩字或改变作者提供的节点尺寸。安全区会减少可用文字面积，但能让居中、换行、尺寸测量和裁剪共享可预测的规则。首次扩展仅覆盖四种新增形状，现有形状的标签行为另行评估。
