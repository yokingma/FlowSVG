# 保持公开契约的内部模块边界

Status: accepted

播放器和 GIF 采样在一次操作中复用同一画面状态求值。React/Vue 共享生命周期协调器，Web Component 保持自己的连接和请求状态。Node GIF 将浏览器、页面和临时资源归属集中到 Node 专属运行模块。

这些内部边界保持公开入口和行为合同稳定。SVG、说明文字和命中测试消费同一时刻及视觉选项下的状态；宿主协调器负责替换顺序和清理，框架适配器负责响应式调度和公开事件。

调用方提供的浏览器由调用方关闭。FlowSVG 负责释放任务拥有的页面、上下文、浏览器和临时目录，包括取消后才完成创建的资源。快速单元测试与实际 Chromium 消费验收分别覆盖运行边界和交付行为。
